An interactive, non-Euclidean 3D web simulation of the **Infinity Castle (*Mugenjō* / 無限城)** from *Demon Slayer (Kimetsu no Yaiba)*.

Experience the bottomless dark void, floating feudal Japanese chambers, vertical wall staircases, and Nakime's dimensional biwa shift mechanics directly in the browser with zero installations.

👉 **[https://abolfazlmk2h.github.io](https://abolfazlmk2h.github.io)**

## ⚔️ Features

- **Procedural Feudal Japanese Architecture**:
  - Procedural wood-grain timber beams, tatami mats, and translucent washi-paper shoji screens generated in real-time on HTML5 canvas.
  - Floating andon paper lanterns casting atmospheric amber light against the dark void.
- **M.C. Escher Non-Euclidean Geometry**:
  - Dozens of interlocking chambers and staircases twisted 90° on walls, suspended vertically, or inverted on ceilings.
- **Nakime's Biwa Strum & Dimensional Shift**:
  - Built-in Web Audio API synthesizer recreating the resonant Japanese *Biwa* lute chord (`Hirajoshi` pentatonic tuning) with zero external audio assets.
  - Pressing **[B]** or clicking the HUD button triggers the biwa strum, causing rooms and staircases to slide and rotate 90° along random axes.
- **Slayer Movement & Combat Dash**:
  - Full first-person 3D mouse-look navigation (WASD + Space).
  - Press **[SHIFT]** to execute a high-speed Thunder / Water Breathing forward dash with camera FOV distortion.
- **Atmospheric Visuals**:
  - Real-time floating ember particles, depth altitude meter, and anime-style HUD.

| Action | Control |
| :--- | :--- |
| **Move** | `W` `A` `S` `D` |
| **Look Around** | `Mouse` (Pointer Lock) |
| **Jump** | `Space` |
| **Slayer Dash** | `Shift` |
| **Nakime Biwa Shift** | `B` or On-Screen Button |
| **Audio Toggle** | On-Screen Button |

## 🛠️ Tech Stack

- **Three.js** (WebGL 3D Rendering & Lighting)
- **Web Audio API** (Custom procedural Biwa synthesizer)
- **HTML5 Canvas** (Procedural textures for wood, tatami, shoji)
- **Pure Static Web** (Hosted on GitHub Pages with 0 build steps)
